## 网页功能

`app.py` 是直接读取 V2 主表和统计视图的正式 Streamlit 应用，包含：

1. **数据库首页**：高校检索、区域与国家／地区筛选、2—4 校比较、六维框架和质量流程。
2. **高校详情**：学校概览、培养目标、课程体系、师资配置、实践环节、评价机制、科研平台与相关机构、科研项目、科研成果、学生发展、来源与附件。
3. **科研与学生发展**：按高校、类别、题名、年份和类型检索。
4. **来源与证据**：来源目录、业务记录证据回查、`raw_fragments` 原文检索和质量状态。
5. **附件下载**：80 份已授权附件逐份下载，显示文件大小、SHA-256、页数、解析状态和下载许可，并提供同步 Excel。

`v_legacy_*` 视图仅用于 V1 无损兼容核对，不再作为正式网页数据源。

## 本地运行

建议使用 Python 3.12。

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py --server.headless=true
```

本地完整成果包同时包含未压缩数据库和压缩副本，应用优先读取：

```text
data/language_ai_cases.db
```

公开 GitHub 仓库不包含超过单文件限制的未压缩数据库，而是包含：

```text
data/language_ai_cases.db.gz
data/database_manifest.json
```

应用在没有 `.db` 文件时会把完整 gzip 副本解压到本机临时目录，复核字节数和 SHA-256 后再启动；校验不一致会停止，不会使用删减库或外部下载地址。

## 数据使用边界

1. 不擅自删除原始资料；V1 每条业务记录的完整原行保存在 `raw_text`。
2. 不凭空补充高校、教师、课程、项目、校友、官方 URL 或访问日期。
3. 不把项目申请书作为高校案例来源，不把科研团队或科研训练路径冒充正式学位项目。
4. 无法可靠归属的内容保留学校层面、跨项目或待核验状态，不强行归入某个项目。
5. 同名课程、研究主题和冲突标签不自动合并或删除；科研和成果采用保守结构化。
6. 图片 OCR 只用于检索和回查候选，不直接生成事实字段。
7. 学生发展只整理公开资料，不补充私人联系方式或推测个人去向。
8. 全部 80 份附件已由用户明确授权公开下载，`allowed` 不等于官方来源已核验。
9. `raw_fragments.disposition` 只能为 `mapped`、`raw_only` 或 `issue_created`，全库 `unprocessed=0`。
10. 后续修改数据库前必须备份，并重新完成 Excel、网页和附件三方一致性验收。
